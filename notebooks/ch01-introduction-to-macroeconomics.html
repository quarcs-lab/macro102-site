Learning goals

Macroeconomics studies the economy as a whole: income, employment, inflation, unemployment and deficits. It works in four steps: document the facts, build a model, compare the model with the facts, and use the model for experiments. By the end of this chapter you will be able to:

  • describe the big facts behind the questions of macroeconomics, using real data for many countries;
  • explain the structure of an economic model: parameters and exogenous variables go in, and endogenous variables come out;
  • solve the supply-and-demand model of the labor market and run experiments with it;
  • tell the long run (economic growth) from the short run (fluctuations around potential output);
  • load data tables with pandas, check them, and draw interactive line charts with Plotly;
  • write short Python functions and turn them into interactive figures with sliders.

def slider_figure(make_figure, name, values, start, label=None):
    """Precompute make_figure(name=value) for every value and join the results with one slider.

    The website cannot run Python, so each model figure gets this precomputed version.
    """
    figures = [make_figure(**{name: v}) for v in values]
    first = values.index(start)
    fig = go.Figure(layout=figures[first].layout)
    owner = []                                  # which figure each trace comes from
    for i, f in enumerate(figures):
        for trace in f.data:
            trace.visible = (i == first)
            fig.add_trace(trace)
            owner.append(i)
    steps = []
    for i, f in enumerate(figures):
        layout = {"title": f.layout.title.to_plotly_json(),
                  "annotations": [a.to_plotly_json() for a in f.layout.annotations],
                  "shapes": [s.to_plotly_json() for s in f.layout.shapes]}
        visible = [o == i for o in owner]
        steps.append(dict(method="update", label=str(values[i]), args=[{"visible": visible}, layout]))
    fig.update_layout(sliders=[dict(active=first, steps=steps, pad=dict(t=60),
                                    currentvalue=dict(prefix=(label or name) + " = "))])
    return fig

The model in code

Chapter 1 uses one small model to show what a model is: supply and demand in the labor market. Workers supply hours of work \(L^s\), and they offer more hours when the wage \(w\) is higher. Firms demand hours of work \(L^d\), and they hire fewer hours when the wage is higher. In the textbook’s worked exercise both relations are straight lines:

\[L^s = \bar{a}\,w + \bar{\ell} \qquad\qquad L^d = \bar{f} - w\]

A bar over a letter marks a parameter, a number the model builder chooses:

  • \(\bar{a}\) is the slope of labor supply: the extra hours offered when the wage rises by one dollar;
  • \(\bar{\ell}\) is the number of hours people would work even at a zero wage;
  • \(\bar{f}\) is the number of hours the firm would hire at a zero wage, a measure of its capacity.

In the code we simply write a, l and f. The wage \(w\) and employment \(L\) are the endogenous variables: the model determines them. The labor market is in equilibrium when supply equals demand, \(\bar{a}w + \bar{\ell} = \bar{f} - w\). Solving this one equation gives

\[w^* = \frac{\bar{f} - \bar{\ell}}{1 + \bar{a}} \qquad\qquad L^* = \bar{f} - w^*\]

With the textbook’s numbers (\(\bar{a} = 2\), \(\bar{\ell} = 30\), \(\bar{f} = 60\)), \(2w + 30 = 60 - w\), so \(w^* = 10\) and \(L^* = 50\).

Python note. def creates a function: a named recipe that takes inputs (the arguments) and gives back a result with return. Writing a=2.0 gives the argument a default value, used whenever we do not pass one. The text in triple quotes is a short description of what the function does. A function can return two results at once, separated by a comma.

def labor_supply(w, a=2.0, l=30.0):
    """Hours of work offered at the wage w: L^s = a w + l   (Exercise 5)."""
    return a * w + l


def labor_demand(w, f=60.0):
    """Hours of work the firm wants to hire at the wage w: L^d = f - w   (Exercise 5)."""
    return f - w


def equilibrium(a=2.0, l=30.0, f=60.0):
    """The wage and employment at which supply equals demand: w* = (f - l) / (1 + a), L* = f - w*."""
    w_star = (f - l) / (1 + a)
    L_star = labor_demand(w_star, f)
    return w_star, L_star

Let us check the functions against the textbook’s answer.

Python note. w_star, L_star = equilibrium() stores the two results of the function in two variables. An f-string such as f"w* = {w_star:.1f}" inserts the value of a variable into a piece of text; :.1f means “show one decimal”.

w_star, L_star = equilibrium()

print(f"At w*, supply = {labor_supply(w_star):.1f} and demand = {labor_demand(w_star):.1f}: the market clears")

What to notice.

What to notice.

  • The ratio rose from about 56 percent in the early 1960s to a peak of 64.7 percent in April 2000.
  • It falls in every recession (the shaded bands), but the last two falls are far deeper than the others: the 2007–09 recession and the Covid-19 collapse of spring 2020.

Key numbers: how deep was each fall?

The textbook says that the two latest recessions brought the sharpest declines in employment in more than 50 years. For each recession, we compare the ratio in the peak month with its lowest value up to two years after the trough (employment often keeps falling after a recession ends).

Figure 6: The structure of economic models

Goal. See what a model does: it takes inputs and determines outcomes.

Every economic model has the same structure. The model builder picks the inputs:

  • parameters, fixed numbers such as \(\bar{a}\), \(\bar{\ell}\), \(\bar{f}\), or a minimum wage set by law;
  • exogenous variables, inputs that may change over time in a way the model builder decides in advance, such as the number of people in the economy.

The model, a set of equations, then determines the endogenous variables, here the wage and employment. The textbook draws this as three boxes: inputs → MODEL → outcomes. Below, the boxes are live: every slider is an input, and the right box shows the outcomes the model computes.

We add one input the textbook mentions as an example of a parameter: a minimum wage. If it is below \(w^*\), it has no effect. If it is above \(w^*\), the wage equals the minimum wage, firms hire only the hours they demand at that wage, and the hours that workers offer but cannot sell are unemployment, \(L^s - L^d\). (Think of \(\bar{\ell}\) as growing with the number of people in the economy: more people offer more hours at any wage.)

Python note. fig.add_shape(type="rect", ...) draws a rectangle and fig.add_annotation(...) writes text; <br> starts a new line and <b>...</b> makes text bold. An annotation with showarrow=True draws an arrow from (ax, ay) to (x, y). max(w_star, w_min) is the larger of the two numbers. The loops run once per box and once per arrow.

def structure_of_models(a=2.0, l=30.0, f=60.0, w_min=0.0):
    """Figure 1.6 as a live model: inputs (parameters) -> MODEL -> outcomes (endogenous variables)."""
    w_star, L_star = equilibrium(a, l, f)
    w = max(w_star, w_min)                         # a minimum wage above w* sets the wage
    L = labor_demand(w, f)                         # firms hire the hours they demand at that wage
    unemployed = max(labor_supply(w, a, l) - L, 0.0)   # hours offered but not hired (zero, not -0.00, if w = w*)
    inputs = (f"<b>INPUTS</b><br><i>parameters and exogenous<br>variables</i><br><br>supply slope a = {a:.1f}"
              f"<br>hours at zero wage l = {l:.0f}<br>demand at zero wage f = {f:.0f}<br>minimum wage = {w_min:.0f}")
    model = "<b>MODEL</b><br><br>Lˢ = a·w + l<br>Lᵈ = f − w<br>Lˢ = Lᵈ, unless<br>a minimum wage<br>is above w*"
    outcomes = (f"<b>OUTCOMES</b><br><i>endogenous variables</i><br><br>wage w = {w:.2f}"
                f"<br>employment L = {L:.2f}<br>unemployment = {unemployed:.2f}")
    fig = go.Figure()
    for x0, x1, text in [[0.0, 0.33, inputs], [0.39, 0.61, model], [0.67, 1.0, outcomes]]:
        fig.add_shape(type="rect", x0=x0, x1=x1, y0=0.12, y1=0.88, fillcolor="#ecf3fa", line=dict(color=BLUE))
        fig.add_annotation(x=(x0 + x1) / 2, y=0.5, text=text, showarrow=False, font=dict(size=13))
    for x_from, x_to in [[0.33, 0.39], [0.61, 0.67]]:
        fig.add_annotation(x=x_to, y=0.5, ax=x_from, ay=0.5, xref="x", yref="y", axref="x", ayref="y",
                           text="", showarrow=True, arrowhead=3, arrowwidth=4, arrowcolor=GREEN)
    fig.update_xaxes(visible=False, range=[0, 1])
    fig.update_yaxes(visible=False, range=[0, 1])
    fig.update_layout(title=f"Inputs → model → outcomes: wage w = {w:.2f}, employment L = {L:.2f}")
    return fig

Figure 8: The labor market

Goal. Draw the supply-and-demand diagram of the labor market and see how the equilibrium moves when a parameter changes.

The diagram puts employment \(L\) on the horizontal axis and the wage \(w\) on the vertical axis. Labor supply \(L^s = \bar{a}w + \bar{\ell}\) slopes up, and labor demand \(L^d = \bar{f} - w\) slopes down. They cross at the equilibrium \((L^*, w^*)\). When you move a slider away from the textbook’s values, the textbook’s curves stay on the chart as dashed gray lines, so you can see the shift.

Python note. np.linspace(0, 30, 100) creates 100 evenly spaced wages from 0 to 30. Because the wage is on the vertical axis, we compute the hours supplied and demanded at each wage and use them as x. go.Figure() starts an empty chart, and each add_trace adds one curve or set of points. As in the textbook, the curves are named on the chart: add_annotation writes the labels Lˢ and Lᵈ at the ends of the curves, and xanchor/yanchor say which corner of the label touches that point.

def labor_market(a=2.0, l=30.0, f=60.0):
    """Figure 1.8: labor supply and demand, and the equilibrium (L*, w*)."""
    w = np.linspace(0, 30, 100)
    w_star, L_star = equilibrium(a, l, f)
    fig = go.Figure()
    if (a, l, f) != (2.0, 30.0, 60.0):             # keep the textbook's curves for comparison
        fig.add_trace(go.Scatter(x=labor_supply(w), y=w, name="Textbook curves (a=2, l=30, f=60)",
                                 line=dict(color=GRAY, width=2, dash="dash")))
        fig.add_trace(go.Scatter(x=labor_demand(w), y=w, showlegend=False, line=dict(color=GRAY, width=2, dash="dash")))
    fig.add_trace(go.Scatter(x=labor_supply(w, a, l), y=w, name="Lˢ", showlegend=False, line=dict(color=TEAL, width=3)))
    fig.add_trace(go.Scatter(x=labor_demand(w, f), y=w, name="Lᵈ", showlegend=False, line=dict(color=BLUE, width=3)))
    w_end = min(30, (100 - l) / a)                 # supply leaves the chart at the top or at the right edge
    fig.add_annotation(x=labor_supply(w_end, a, l), y=w_end, text="Lˢ", showarrow=False,
                       xanchor="right", yanchor="bottom", font=dict(size=18, color=TEAL))
    fig.add_annotation(x=labor_demand(30, f), y=30, text="Lᵈ", showarrow=False, xshift=-4,
                       xanchor="right", yanchor="top", font=dict(size=18, color=BLUE))
    fig.add_trace(go.Scatter(x=[0, L_star, L_star], y=[w_star, w_star, 0], mode="lines", showlegend=False,
                             line=dict(color="black", width=1, dash="dot")))
    fig.add_trace(go.Scatter(x=[L_star], y=[w_star], mode="markers", name="Equilibrium (L*, w*)",
                             marker=dict(color="black", size=12)))
    fig.update_layout(title=f"Equilibrium: wage w* = {w_star:.2f}, employment L* = {L_star:.2f}", showlegend=True,
                      xaxis=dict(title="Employment, L", range=[0, 100], tickvals=[20, 40, 60, 80, 100]),
                      yaxis=dict(title="Wage, w", range=[0, 30]))
    return fig

Summary

  • Macroeconomics studies the economy as a whole. Its big questions start from facts like these: huge income gaps across countries, deep recessions such as 2008–09 and 2020, the inflation of the 1970s and of 2021–22, high unemployment in Europe, and large U.S. budget and trade deficits.
  • It answers them in four steps: document the facts, build a model, compare the model with the facts, and use the model for experiments.
  • A model takes parameters and exogenous variables as inputs and determines the endogenous variables. In the labor-market model, \(w^* = (\bar{f} - \bar{\ell})/(1 + \bar{a})\) and \(L^* = \bar{f} - w^*\).
  • U.S. GDP per person has grown at almost 2 percent a year since 1870 (the long run), with deviations from potential output that are small except in the Great Depression and World War II (the short run).
  • Checking claims against the data matters: some textbook numbers hold exactly, others change with newer data.
  • The next chapter shows how GDP, the measure behind most of these figures, is defined and measured.
