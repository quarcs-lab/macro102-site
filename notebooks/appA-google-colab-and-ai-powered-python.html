Learning goals

This book asks you to run economics, not only to read it. Everything happens in a web browser, with nothing to install, and with an AI assistant one click away. By the end of this appendix you will be able to:

  • explain what Google Colab is, why this book uses it, and what its limits are;
  • open any notebook of the book in Colab, run it, move its sliders, save your own copy and close it properly;
  • write short Python programs with numbers, variables, lists, loops, if statements and functions, using examples from the book’s models;
  • use Gemini in Colab to explain code, write new code, fix errors, run a whole analysis and tutor you step by step, and check what it produces before you trust it;
  • load, explore and reshape a real data table with pandas, compute with NumPy, draw interactive charts with Plotly, and add sliders with ipywidgets;
  • put these pieces together in a small data project, first by hand and then with AI: which economies grew fastest after 1990?

A.1 What is Google Colab?

A notebook is a document that mixes three things: text (like this paragraph), code, and the results of that code (numbers, tables and charts). You read it from top to bottom. When you change a piece of code and run it again, its result updates right below it. The explanation, the computation and the evidence sit side by side, which makes notebooks a good way to learn.

Google Colab (short for Colaboratory) is a free Google service that runs notebooks inside your web browser. Its notebooks use the open Jupyter format (.ipynb files), the standard in data science. The code does not run on your laptop. It runs on a computer in one of Google’s data centres, called the runtime, and the results come back to your browser.

Colab also has an AI assistant built in: Gemini, Google’s large language model. You can ask it, in plain English, to explain a line of code, write a chart, fix an error or carry out a whole analysis. Section A.5 shows how, and why you still need to know some Python to use it well.

A.1.1 Why this book uses Colab

  • Nothing to install. Python and all the libraries this book needs (NumPy, pandas, Plotly and ipywidgets) are already installed in Colab. You only need a web browser and a Google account.
  • The same setup for everyone. Every reader runs the same versions of the same tools. Code that works for the author works for you, on Windows, macOS, Linux or a Chromebook.
  • Live models. In Colab, the model figures of the book get sliders and buttons. Move a slider and the model is solved again on the spot.
  • AI built in. Gemini sees your notebook, so it can explain the code in front of you, write the next cell, and fix the error you just got. It can also act as a tutor that guides you instead of giving away the answer.
  • Easy to save and share. You can save your own copy of any notebook in Google Drive, and share it with a classmate or an instructor with a link, much like a Google Doc.
  • Data straight from the source. Each notebook reads its data files over the internet from the book’s GitHub repository, so you never have to download or upload a data file.

A.1.2 What to keep in mind

  • The runtime is temporary. When you close the notebook, or leave it idle for a while, Colab disconnects the runtime and forgets every variable. Free sessions also have a maximum length of several hours (see the Colab FAQ). For this book that is no problem: click Runtime → Run all again and everything is rebuilt in a few seconds.
  • Your edits are not saved automatically in a notebook you opened from GitHub. Save your own copy in Google Drive first (Section A.2, step 6).
  • Free resources are shared. The free tier limits how many notebooks can run at the same time. Close a runtime properly when you are done (Section A.2, step 7).
  • Not every account has Gemini. The AI features need a Google account of someone aged 18 or older in a supported country. In a school or company account, the administrator decides whether Colab and its AI features are switched on. Everything in this book except Section A.5 and Step 5 of Section A.7 works without Gemini.
  • You need to be online, because the runtime, the data and the AI assistant all live on the internet.

A.3 Working in a notebook

A notebook is a list of cells. Text cells are written in Markdown, a simple way to format text (**bold**, *italic*, # Heading), and they can hold equations such as \(y = \bar{A}k^{1/3}\). Code cells hold Python. To run a code cell, click inside it and press Shift+Enter, or click the round ▶ button at its left. Try it on the cell below.

# A code cell: Python works out the expression and shows the result of the last line
2 + 3
5

Only the result of the last line of a cell is shown automatically. To show anything else, use print.

print("Hello, Colab!")
x = 10
x * 2          # the last line: its value is shown below the cell

20

A.3.1 The order of cells matters

A notebook remembers every variable you have created, in the order in which you ran the cells, not the order in which they appear on the page. The next two cells work only if you run the first one before the second. If you open a notebook and run a cell in the middle, you may see a NameError (Section A.4.8), because a cell above it has not run yet. The cure is almost always Runtime → Run all, or Runtime → Run before followed by the cell itself.

interest_rate = 0.05          # create a variable...
interest_rate * 100           # ...and use it in a later cell
5.0

A.4 Python fundamentals

Python is a programming language that reads almost like English. This section covers the handful of ideas you need for the whole book, and every example comes from the book’s economics. Take your time here, even though an AI assistant can write code for you. You can only check code you can read (Section A.5.1).

A.4.1 Numbers and arithmetic

Python works like a calculator. ** raises a number to a power, which is all you need for compound growth.

print(7 + 3, 7 - 3, 7 * 3, 7 / 3)     # add, subtract, multiply, divide
print(7 // 3, 7 % 3)                 # whole-number division and its remainder
print(2 ** 10)                       # a power: 2 to the 10th
10 4 21 2.3333333333333335
2 1
1024

An economy that grows at 2 percent a year is multiplied by 1.02 every year. After 35 years it is \(1.02^{35}\) times as large:

1.02 ** 35
1.9998895526624565

It has almost exactly doubled. This is the rule of 70 of Chapter 3 at work: at 2 percent a year, a variable doubles in about 70/2 = 35 years.

A.4.2 Variables

A variable is a name for a value. The = sign means “store the value on the right under the name on the left”. Names may contain letters, digits and underscores, but not spaces, and they are case-sensitive (GDP and gdp are different names). In this book the names follow the notation of the textbook, such as s, d, A, k_star and y_star.

y_1990 = 47713      # U.S. GDP per person in 1990, 2022 dollars (Maddison data, Section A.6)
y_2022 = 75459      # the same in 2022
growth_factor = y_2022 / y_1990
growth_factor
1.5815186636765661

From the growth factor we get the average annual growth rate: the rate \(g\) that turns \(y_{1990}\) into \(y_{2022}\) in 32 years, \(y_{2022} = y_{1990}(1+g)^{32}\), so \(g = (y_{2022}/y_{1990})^{1/32} - 1\).

g = growth_factor ** (1 / 32) - 1
g
0.014427636896671148

A.4.3 Types of values and f-strings

Every value has a type. The four you will meet most are whole numbers (int), decimal numbers (float), text (str, for string, written in quotes) and truth values (bool: True or False).

country = "United States"           # a string
years = 2022 - 1990                 # an int
g = growth_factor ** (1 / years) - 1    # a float
is_rich = y_2022 > 50000            # a bool, the result of a comparison
print(type(country), type(years), type(g), type(is_rich))
<class 'str'> <class 'int'> <class 'float'> <class 'bool'>

Python note. An f-string is a string with an f before the opening quote. Python replaces each {...} inside it with the value of the expression. After a colon you can set the format: {g:.2%} shows g as a percentage with 2 decimals, {y:,.0f} shows y with a thousands separator and no decimals.

print(f"{country}: GDP per person grew from {y_1990:,.0f} to {y_2022:,.0f} dollars,")
print(f"or {g:.2%} a year on average over {years} years.")
United States: GDP per person grew from 47,713 to 75,459 dollars,
or 1.44% a year on average over 32 years.

A.4.4 Lists and loops

A list holds several values in order, inside square brackets. Python counts positions from 0, so countries[0] is the first element and countries[-1] the last one.

countries = ["United States", "Japan", "China"]
print(countries[0], "|", countries[-1], "|", len(countries), "countries")
countries.append("India")        # add an element at the end
countries
United States | China | 3 countries
['United States', 'Japan', 'China', 'India']

A for loop repeats the indented lines below it, once for each value. range(1, 6) gives the whole numbers 1, 2, 3, 4 and 5. Note the colon at the end of the for line and the four spaces of indentation: they tell Python which lines belong to the loop.

# Compound growth, year by year: income grows by 2 percent each year
y = 100.0
for year in range(1, 6):
    y = y * 1.02
    print(f"year {year}: {y:.2f}")
year 1: 102.00
year 2: 104.04
year 3: 106.12
year 4: 108.24
year 5: 110.41

Loops are how the book simulates models over time. Here is the capital accumulation equation of the Solow model (Chapter 5), \(k_{t+1} = k_t + s\,k_t^{1/3} - d\,k_t\), run for 50 years. Each year, capital per person grows by investment and shrinks by depreciation.

s, d = 0.2, 0.1        # investment rate and depreciation rate
k = 1.0                # capital per person in year 0
path = [k]             # a list that will hold the whole path
for t in range(50):
    k = k + s * k ** (1 / 3) - d * k
    path.append(k)
k_star = (s / d) ** 1.5                 # the steady state of this model, (s/d)^(3/2)
print(f"k after 10 years: {path[10]:.3f}, after 50 years: {path[50]:.3f}")
print(f"steady state k* = {k_star:.3f}")
k after 10 years: 1.828, after 50 years: 2.761
steady state k* = 2.828

Capital rises quickly at first and then slows down as it approaches the steady state: the principle of transition dynamics of Chapter 5.

A.4.5 Making decisions with if

if, elif (else if) and else run different lines depending on a condition. The comparisons are >, <, >=, <=, == (equal; note the double sign) and != (not equal).

g_percent = 1.4                  # an average growth rate, in percent a year
if g_percent >= 3:
    label = "fast"
elif g_percent >= 1:
    label = "moderate"
else:
    label = "slow or negative"
print(f"Growth of {g_percent}% a year is {label}.")
Growth of 1.4% a year is moderate.

A.4.6 Dictionaries

A dictionary stores values under names (keys), inside curly braces. The book uses dictionaries for sets of parameters and for colors.

params = {"s": 0.2, "d": 0.1, "A": 1.0}
print(params["s"])               # look up a value by its key
params["s"] = 0.3                # change it
for key in params:
    print(key, "=", params[key])
0.2
s = 0.3
d = 0.1
A = 1.0

A.4.7 Functions

A function packs a few lines of code under a name, so you can reuse them. def starts the definition, the names in parentheses are its arguments, and return sends back the result. An argument with a default value (A=1.0) can be left out when you call the function. The text in triple quotes, the docstring, says what the function does. In the chapters each model equation becomes one short function like this one, the production function of Chapter 4.

def output(k, A=1.0):
    """Output per person in the production model of Chapter 4: y = A k^(1/3)."""
    return A * k ** (1 / 3)

print(output(8))           # k = 8 and the default A = 1
print(output(8, A=2.0))    # the same capital with twice the productivity
2.0
4.0

A second function turns the rule of 70 into code and uses a loop to try several growth rates.

def years_to_double(g_percent):
    """Rule of 70 (Chapter 3): something growing at g percent a year doubles in about 70/g years."""
    return 70 / g_percent

for g_percent in [1, 2, 3.5, 7]:
    print(f"growth of {g_percent}% a year: doubles in about {years_to_double(g_percent):.0f} years")
growth of 1% a year: doubles in about 70 years
growth of 2% a year: doubles in about 35 years
growth of 3.5% a year: doubles in about 20 years
growth of 7% a year: doubles in about 10 years

A.4.8 Libraries and errors

A library (or package) is a collection of functions that someone else has written. import loads one. The built-in math library, for example, has the natural logarithm, which gives the exact doubling time \(\ln 2 / \ln(1+g)\) to compare with the rule of 70. The rule is very close at low growth rates and a little off at high ones.

import math
for g_percent in [2, 7]:
    exact = math.log(2) / math.log(1 + g_percent / 100)
    rule = years_to_double(g_percent)
    print(f"At {g_percent}% a year: exactly {exact:.1f} years; rule of 70: {rule:.1f} years")
At 2% a year: exactly 35.0 years; rule of 70: 35.0 years
At 7% a year: exactly 10.2 years; rule of 70: 10.0 years

Everyone writes code with mistakes. When Python cannot run a line, it stops and prints an error message (a traceback). Read it from the bottom: the last line names the kind of error and what went wrong, and an arrow ----> points to the line that failed. Screenshot A.11 shows a typo in a variable name, which gives a NameError. Under the message, Colab offers an Explain error button that asks Gemini for help (Section A.5.4). Read the message yourself first: most errors take a few seconds to fix once you know where to look.

Screenshot A.11. A NameError (1): the variable grwoth was never created (the name is growth). Below it, the Explain error button (2).

You can also catch an error yourself with try ... except. Python tries the indented lines under try; if they fail with the named error, it runs the lines under except instead of stopping. The setup cell of every chapter uses this to run one line that only works in Colab.

try:
    "GDP in " + 2025          # text plus a number: Python refuses to guess what you mean
except TypeError as error:
    print("TypeError:", error)
print("GDP in " + str(2025))    # the fix: turn the number into text first
TypeError: can only concatenate str (not "int") to str
GDP in 2025

A.5.1 Why you still need to read Python

An AI assistant writes code that runs. That is not the same as code that answers your question correctly. A wrong formula, a wrong column or a wrong year range gives no error message: you get a number that looks fine, and you only notice the mistake if you can read the code and know what the number should be.

Here is a mistake that AI assistants (and people) make all the time. Ask for “the average growth rate” of a series, and you often get the average of the yearly growth rates. Take an income that rises by 50 percent in one year and falls by 50 percent in the next:

incomes = [100, 150, 75]     # income rises 50 percent, then falls 50 percent
yearly = []
for t in range(1, len(incomes)):
    yearly.append((incomes[t] / incomes[t - 1] - 1) * 100)
print("yearly growth rates (percent):", yearly)
print("average of the yearly rates:", sum(yearly) / len(yearly))

g_true = ((incomes[-1] / incomes[0]) ** (1 / 2) - 1) * 100     # the formula of Section A.4.2
print(f"true average annual growth rate: {g_true:.1f} percent")
yearly growth rates (percent): [50.0, -50.0]
average of the yearly rates: 0.0
true average annual growth rate: -13.4 percent

The average of the yearly rates is 0, which suggests income is back where it started. In fact income fell from 100 to 75, a loss of 25 percent, or about −13.4 percent a year. The right formula is the compound (geometric) rate of Section A.4.2. With real data the gap can be large: in Section A.7 the average of the yearly rates turns a country that got poorer into one that seems to grow fast.

def slider_figure(make_figure, name, values, start, label=None):
    """Precompute make_figure(name=value) for every value and join the results with one slider.

    The website cannot run Python, so each interactive figure also gets this precomputed version.
    """
    figures = [make_figure(**{name: v}) for v in values]
    first = values.index(start)
    fig = go.Figure(layout=figures[first].layout)
    owner = []                                  # which precomputed figure each trace comes from
    for i, f in enumerate(figures):
        for trace in f.data:
            trace.visible = (i == first)
            fig.add_trace(trace)
            owner.append(i)
    steps = []
    for i, f in enumerate(figures):
        layout = {"title": f.layout.title.to_plotly_json(),
                  "annotations": [a.to_plotly_json() for a in f.layout.annotations],
                  "shapes": [s.to_plotly_json() for s in f.layout.shapes]}
        visible = [o == i for o in owner]
        steps.append(dict(method="update", label=str(values[i]), args=[{"visible": visible}, layout]))
    fig.update_layout(sliders=[dict(active=first, steps=steps, pad=dict(t=60),
                                    currentvalue=dict(prefix=(label or name) + " = "))])
    return fig

A.6.6 ipywidgets: sliders and menus

ipywidgets turns the arguments of a function into controls. interact(f, ...) draws one control for each argument and calls f again every time you move one. This is how every model figure in the book becomes interactive: we write a function that returns a figure, and hand it to interact.

def production_figure(A=1.0, alpha=1 / 3):
    """Production function y = A k^alpha (Chapter 4), with fixed axes so changes are visible."""
    k = np.linspace(0, 10, 200)
    fig = go.Figure()
    fig.add_trace(go.Scatter(x=k, y=k ** (1 / 3), mode="lines", name="Baseline: A = 1, α = 1/3",
                             line=dict(color=GRAY, dash="dash")))
    fig.add_trace(go.Scatter(x=k, y=A * k ** alpha, mode="lines", name="Your production function",
                             line=dict(color=TEAL, width=3)))
    fig.update_layout(title=f"Output per person at k = 8: y = {A * 8 ** alpha:.2f} (baseline 2.00)",
                      xaxis=dict(title="Capital per person, k", range=[0, 10],
                                 tickvals=[2, 4, 6, 8, 10]),
                      yaxis=dict(title="Output per person, y", range=[0, 7]))
    return fig

Python note. FloatSlider makes a slider for decimal numbers, from min to max in steps of step, starting at value. Dropdown makes a menu; each option is a pair ("label shown", value). style=WIDE shows the whole description. The ; at the end hides an extra line of text.
