The model in code

Paul Romer divides economic goods into objects and ideas. Objects are things: land, oil, machines, workers. Ideas are instructions for using objects, such as the design of a phone or the formula of a drug. The key difference is that ideas are nonrival: my use of the quadratic formula does not leave less of it for you. So the same idea can serve any number of workers and factories at once.

Nonrivalry gives increasing returns. Write output as \(Y_t = A_tK_t^{1/3}L_t^{2/3}\) (6.1), where \(A_t\) is the stock of ideas. Doubling the objects \(K\) and \(L\) doubles output, because the new factory can use the same ideas. Doubling the ideas as well therefore more than doubles output.

Python note. def creates a function: a named recipe that takes inputs (the arguments) and gives back a result with return. The text in triple quotes is a short description of what the function does. ** means “to the power of”. An f-string such as f"{ratio:.2f}" inserts the value of a variable into a piece of text; :.2f means “two decimals”.

def output_with_ideas(K, L, A):
    """Production with objects and ideas: Y = A K^(1/3) L^(2/3)   (equation 6.1)."""
    return A * K ** (1 / 3) * L ** (2 / 3)

The Romer model has no capital, so that we can see the role of ideas clearly. It has five equations and five unknowns (textbook Table 6.1):

Equation Name
\(Y_t = A_t^{\gamma}L_{yt}\) (6.2) output: workers \(L_{yt}\) use the whole stock of ideas \(A_t\)
\(\Delta A_{t+1} = \bar{z}L_{at}\) (6.3) new ideas: each researcher finds \(\bar{z}\) ideas a year
\(L_{yt} + L_{at} = N_t\) (6.4) people either make goods or do research
\(\Delta N_{t+1}/N_t = \bar{n}\) (6.5) the population grows at rate \(\bar{n}\)
\(L_{at} = \bar{\ell}N_t\) (6.6) a constant share \(\bar{\ell}\) of the population does research

The parameter \(\gamma\) measures how important ideas are, and it equals the degree of increasing returns. Output per person is \(y_t = A_t^{\gamma}(1-\bar{\ell})\) (6.7). It depends on the total stock of ideas, not on ideas per person: that is nonrivalry at work.

On the balanced growth path (BGP), where all growth rates are constant, the stock of ideas grows at the rate of population, \(g_A^* = \bar{n}\), and is \(A_t^* = \bar{z}\bar{\ell}N_t/\bar{n}\) (6.8). Putting this into (6.7) gives the two key results:

\[y_t^* = (1-\bar{\ell})\left(\frac{\bar{z}\bar{\ell}N_t}{\bar{n}}\right)^{\gamma} \quad (6.10) \qquad\qquad g_y^* = \gamma\bar{n} \quad (6.11)\]

Simulating the Romer model year by year

To draw the experiments of the chapter, we let a computer apply the equations one year at a time. The function below starts on the BGP in 2000 and changes \(\bar{z}\) and \(\bar{\ell}\) in change_year. It returns output per person and, for comparison, the BGP level for the parameters in force in each year. Both are scaled so that \(y_{2000} = 100\), as in the textbook.

Python note. np.arange(2000, 2091) gives the years 2000, 2001, …, 2090. A for loop repeats the indented lines once for each year, and if ... else chooses between two cases. y_path.append(...) adds a number to the end of a list. Writing gamma=0.6 gives the argument a default value, used whenever we do not pass one.

def simulate_romer(z_old=1.0, z_new=1.0, l_old=0.1, l_new=0.1, gamma=0.6, n=0.05,
                   change_year=2030, first_year=2000, last_year=2090):
    """Romer model (equations 6.2-6.6) year by year; z and l change to z_new, l_new in change_year."""
    years = np.arange(first_year, last_year + 1)
    N = 1.0                                         # population in the first year
    A = z_old * l_old * N / n                       # start with the BGP stock of ideas, equation (6.8)
    y_path, bgp_path = [], []
    for year in years:
        if year < change_year:
            z, l = z_old, l_old
        else:
            z, l = z_new, l_new
        y_path.append(A ** gamma * (1 - l))                  # output per person, equation (6.7)
        bgp_path.append((1 - l) * (z * l * N / n) ** gamma)  # BGP level, equation (6.10)
        A = A + z * l * N                           # new ideas from the researchers, equation (6.3)
        N = N * (1 + n)                             # population growth, equation (6.5)
    scale = 100 / y_path[0]                         # normalization: y = 100 in the first year
    return years, scale * np.array(y_path), scale * np.array(bgp_path)

A quick check. With yearly steps, output per person on the BGP grows by the factor \((1+\bar{n})^{\gamma}\) each year, which is very close to \(1 + \gamma\bar{n}\).

Figure 1: A fixed cost leads to increasing returns

Goal. See why a fixed cost of research turns a constant-returns technology into one with increasing returns.

Once a new antibiotic has been invented, making it is ordinary production: each $10 buys one dose, so \(Y = X/10\) when \(X\) dollars are spent. Doubling spending doubles the doses, and the average product \(Y/X\) is constant. But first someone must pay the research cost \(\bar{F} = \$2.5\) billion. Including it, \(Y = (X-\bar{F})/10\) for \(X > \bar{F}\), and

\[\frac{Y}{X} = \frac{1}{10}\left(1 - \frac{\bar{F}}{X}\right),\]

which rises with the scale of production \(X\).

In the chart, \(X\) is in billions of dollars and \(Y\) in millions of doses, so \(Y = 100\,(X - \bar{F})\).

def doses(X, F=0.0):
    """Antibiotic doses (millions) from spending X (billions of $) with a fixed cost F: Y = (X - F)/10."""
    return 100 * np.maximum(X - F, 0)               # zero until the fixed cost is paid

Python note. np.maximum(X - F, 0) takes, for each number, the larger of \(X - \bar{F}\) and 0, so output is zero until the fixed cost is covered. make_subplots(rows=1, cols=2) creates a figure with two panels side by side, and row=..., col=... tells add_trace where to draw. In if ... elif ... else, elif (“else if”) adds a second test: Python runs the first branch whose test is true.

def fixed_cost(F=2.5, X=7.2):
    """Figure 6.1: constant returns (a) and the same technology with a fixed cost F (b)."""
    x = np.linspace(0, 10, 201)
    half = X / 2                                     # the smaller of the two scales we compare
    fig = make_subplots(rows=1, cols=2, subplot_titles=("(a) Constant returns: Y = X/10", f"(b) Fixed cost F̄ = {F} billion"))
    fig.add_trace(go.Scatter(x=x, y=doses(x), line=dict(color=TEAL, width=3)), row=1, col=1)
    fig.add_trace(go.Scatter(x=x, y=doses(x, F), line=dict(color=GREEN, width=3)), row=1, col=2)
    for scale in [half, X]:                          # a dot in (a) and an average-product ray (slope Y/X) in (b)
        fig.add_trace(go.Scatter(x=[scale], y=[doses(scale)], marker=dict(color="black", size=10)), row=1, col=1)
        fig.add_trace(go.Scatter(x=[0, scale], y=[0, doses(scale, F)], mode="lines+markers", marker=dict(color="black", size=[0, 10]),
                                 line=dict(color="black", dash="dash")), row=1, col=2)     # a dot at the far end only
    if F > 0:
        fig.add_annotation(x=2.6, y=620, xref="x2", yref="y2", showarrow=False, font=dict(size=13),
                           text="The average product Y/X<br>(slope of a dashed ray)<br>rises with scale")
    if doses(half, F) > 0:
        gain = f"×{doses(X, F) / doses(half, F):.2f}"
    elif doses(X, F) > 0:
        gain = "from zero"
    else:
        gain = "still zero"                          # all the spending goes to research
    fig.update_xaxes(title_text="Input, X (billions of dollars)", range=[0, 10], tickvals=[2, 4, 6, 8, 10])  # no label at the bottom-left corner
    fig.update_yaxes(range=[0, 1000])                # the same scale in both panels, so (b) never leaves the chart
    fig.update_layout(title=f"Doubling X from {half:.1f} to {X:.1f} billion: output ×2 in (a), {gain} in (b)",
                      yaxis=dict(title="Output, Y (millions of doses)"), showlegend=False)
    return fig

Figure 2: The balanced growth path in the Romer model

Goal. See that the Romer model produces sustained growth in output per person, at the rate \(g_y^* = \gamma\bar{n}\).

More people means more researchers, and more researchers find more ideas. Because ideas are nonrival, every new idea raises the income of everyone. So as long as the population grows, output per person grows too, at a constant rate.

On a ratio scale a variable that grows at a constant rate is a straight line, and the slope of the line is the growth rate. The chart uses vertical_axis and add_label from “The model in code”.

Figure 3: A rise in research productivity

Goal. Run the first experiment: in 2030, research productivity \(\bar{z}\) rises permanently, for example because artificial intelligence makes it easier to find new ideas.

Step 1: the long run. The growth rate \(g_y^* = \gamma\bar{n}\) does not depend on \(\bar{z}\), so long-run growth is unchanged. But the BGP level in (6.10) is proportional to \(\bar{z}^{\gamma}\), so the new BGP is higher by the factor \((\bar{z}'/\bar{z})^{\gamma}\): a level effect.

Step 2: the transition. In 2030 the stock of ideas has not changed yet, so the economy is suddenly below its new BGP. By the principle of transition dynamics, it grows fast at first, and then more and more slowly as it gets close to the new path.

We reuse simulate_romer. The old BGP is simply a simulation in which nothing changes, and experiment_chart from “The model in code” draws the three paths.

Figure 4: A rise in the research share

Goal. Run the second experiment: in 2030 the economy permanently puts a larger share \(\bar{\ell}\) of its people into research.

Step 1: the long run. Again \(g_y^* = \gamma\bar{n}\) does not change. The BGP level (6.10) can be written \(y_t^* = (1-\bar{\ell})\,\bar{\ell}^{\gamma}\,(\bar{z}N_t/\bar{n})^{\gamma}\), so \(\bar{\ell}\) enters twice: more researchers mean more ideas (\(\bar{\ell}^{\gamma}\)), but fewer workers making goods (\(1-\bar{\ell}\)). For a research share that is not too large, the first effect wins and the new BGP is higher.

Step 2: the transition. In 2030 the stock of ideas is still the same, but fewer people produce goods. So output per person falls on impact. After that, the economy is far below its new BGP and grows fast to catch up.

def slowdown_chart(window=10):
    """Figure 6.6: average annual growth of U.S. GDP per person over the preceding `window` years."""
    table = gdp.copy()
    table["growth"] = 100 * (np.log(table.gdp_pc) - np.log(table.gdp_pc.shift(window))) / window

    since = table[table.year >= 2009].growth.mean()

Figure 7: The word processor production function

Goal. Apply the economics of ideas to software: a large fixed cost and a tiny marginal cost.

This figure comes from a worked exercise in the textbook. A word processor with perfect speech recognition costs $100 million to create, and each copy then costs $1 to distribute. With \(X\) million dollars spent, the number of copies (in millions) is

\[Y = X - 100 \quad \text{for } X > 100, \qquad Y = 0 \text{ otherwise.}\]

If the firm sells copies at a price \(p\) above the marginal cost of $1, it breaks even when revenue covers the total cost: \(pY = 100 + Y\), so \(Y = 100/(p-1)\) million copies.

Figure 8: Output after a rise in the investment rate

Goal. Combine the two models: a Solow economy with capital that sits on top of the Romer growth in ideas. Then raise the investment rate.

The combined model (textbook Section 6.9) adds capital to the Romer model. Output is \(Y_t = A_t^{\gamma}K_t^{1/3}L_{yt}^{2/3}\) (6.16), capital accumulates as in Chapter 5, \(\Delta K_{t+1} = \bar{s}Y_t - \bar{d}K_t\) (6.17), and ideas, workers and population follow the Romer equations (6.18)–(6.21). On the balanced growth path,

\[g_y^* = \tfrac{3}{2}\gamma\bar{n} \quad (6.25) \qquad\qquad y_t^* = \left(\frac{\bar{s}}{g_Y^* + \bar{d}}\right)^{1/2} \left(A_t^*\right)^{3\gamma/2}(1-\bar{\ell}) \quad (6.27)\]

where \(g_Y^* = g_y^* + \bar{n}\) is the growth of total output. (The textbook prints (6.27) for the case \(\gamma = 1\), where the exponent on \(A_t^*\) is \(3/2\).) Growth is faster than in the Romer model: ideas raise output, the extra output is partly invested, and the extra capital raises output again. A higher investment rate \(\bar{s}\) raises the level of the BGP, not its growth rate.

The function below is the combined model’s version of simulate_romer. In yearly steps, output per person on the BGP grows by the factor \((1+\bar{n})^{3\gamma/2}\), which is close to \(1 + \tfrac{3}{2}\gamma\bar{n}\).

def simulate_combined(s_old=0.05, s_new=0.05, gamma=2 / 3, n=0.03, d=0.02, z=1.0, l=0.1,
                      change_year=2030, first_year=2000, last_year=2090):
    """Combined Solow-Romer model (equations 6.16-6.21) year by year; s changes to s_new in change_year."""
    years = np.arange(first_year, last_year + 1)
    g_y = (1 + n) ** (1.5 * gamma) - 1              # BGP growth of output per person, yearly steps
    g_Y = (1 + g_y) * (1 + n) - 1                   # BGP growth of total output
    N = 1.0
    A = z * l * N / n                               # BGP stock of ideas, as in the Romer model
    K = (s_old / (g_Y + d)) ** 1.5 * A ** (1.5 * gamma) * (1 - l) * N   # BGP capital, from (6.26)
    y_path, bgp_path = [], []
    for year in years:
        if year < change_year:
            s = s_old
        else:
            s = s_new
        Y = A ** gamma * K ** (1 / 3) * ((1 - l) * N) ** (2 / 3)        # output, equation (6.16)
        y_path.append(Y / N)
        bgp_path.append((s / (g_Y + d)) ** 0.5 * A ** (1.5 * gamma) * (1 - l))   # equation (6.27)
        K = K + s * Y - d * K                       # capital accumulation, equation (6.17)
        A = A + z * l * N                           # new ideas, equation (6.18)
        N = N * (1 + n)                             # population growth, equation (6.21)
    scale = 100 / y_path[0]                         # normalization: y = 100 in the first year
    return years, scale * np.array(y_path), scale * np.array(bgp_path)

Summary

  • Romer divides goods into objects and ideas. Ideas are nonrival: they can be used by any number of people at once, so there are constant returns to objects and increasing returns to objects and ideas together.
  • Increasing returns come with fixed research costs. If prices equaled marginal cost, nobody could pay for research, so innovation needs patents, secrecy, public funding or prizes.
  • In the Romer model, more people mean more researchers and more ideas, and long-run growth is \(g_y^* = \gamma\bar{n}\). Changes in research productivity or the research share have level effects and transition dynamics, but leave long-run growth unchanged.
  • The combined Solow–Romer model grows at \(\tfrac{3}{2}\gamma\bar{n}\): capital amplifies the growth of ideas. Investment rates and other Solow parameters set the level of the BGP, and the principle of transition dynamics explains why countries grow at different rates for decades.
